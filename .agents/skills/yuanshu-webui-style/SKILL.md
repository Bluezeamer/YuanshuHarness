# 元枢 WebUI 风格：改良版瑞士国际主义

先看 [assets/reference.html](assets/reference.html)（可直接用浏览器打开的静态成品，四个 tab、重连态、审批弹窗都能切换），它是风格的唯一视觉真相；本文是它的规则化说明。两者冲突时以 reference.html 为准，并回头修本文。

## 一句话

一块按网格排版的控制台：墨色结构、1px 发丝线、暖白底、单一强调色，把事件序号当作可见的标尺。拒绝"灰底加一个强调色"的默认后台。

用户是单人开发者，长时间盯着看，中文界面，信息密度偏高。装饰让位于信息。

## 颜色：各司其职

只用语义变量，组件里不写死色值（见「主题变量」）。

| 变量 | 默认值 | 角色 |
|---|---|---|
| `--bg` | `#f7f6f2` | 页面底，偏暖灰白 |
| `--panel` | `#fcfbf8` | 面板、顶栏、输入栏 |
| `--ink` | `#16161a` | 结构、选中、主文字 |
| `--mute` | `#585851` | 次要文字（对比度满足 4.5:1） |
| `--line` / `--line2` | ink 14% / 7% | 发丝线 / 更淡的行分隔 |
| `--acc` | `#c4331b` | 红：只表示"需要人介入"——停止、拒绝、失败、序号缺口、待审批 |
| `--live` | `#1f4fd8` | 蓝：进行中——运行、流式、排队、焦点环 |
| `--ok` | `#1d6b45` | 绿：完成、在线 |

规则：
- 红色出现就意味着有事要人处理。不要拿红色做装饰、品牌大色块之外的强调。品牌小方块（12px）是唯一例外。
- 状态不只靠颜色：同时给文字或形状（缺口是斜线格，运行中有闪烁，完成有文字"完成"）。
- 选中态用墨色：左侧 3px 墨条，或整块反白（墨底、bg 字）。不用强调色做选中。

## 字体

| 变量 | 默认栈 | 用途 |
|---|---|---|
| `--font-sans` | `Inter, "Noto Sans SC", sans-serif` | 界面正文与标题；Inter 管西文和数字，中文回退到 Noto Sans SC |
| `--font-mono` | `"Cascadia Code", "Cascadia Mono", ui-monospace, Consolas, monospace` | 代码、命令、事件序号、地址、数字列；开启 `tabular-nums` |

中文字体先用默认，后续整体替换时只改 `--font-sans` 里的中文部分。不要在组件里直接写字体名。

字号：正文 13.5px/1.55；次要 12 到 12.5px；页面标题 22 到 26px，粗体 700，字距 -0.01em 左右；对话中用户消息 16px/600。

## 形与线

- 直角为主，最大圆角 3px（按钮、标签、输入框 2px）。状态点是唯一的圆。
- 层次靠 1px 发丝线和对齐，不靠阴影。无阴影、无渐变、无玻璃。顶栏与输入栏的分界用 1px 墨线加强。
- 唯一的模糊：审批弹窗遮罩 `backdrop-filter: blur(3px)`。

## 布局

- 外壳：顶栏 48px（品牌、tab、右侧连接状态）；tab 下方一条 3px 墨色指示条，切换时滑动（500ms，见动效）。
- 对话页：左栏会话列表 268px；右侧标题行、序号标尺、消息流、底部输入栏（发送、运行中出现红色"停止"）。
- 消息流：左侧 72px 角色列（用户 / 恒侍 / 排队中），正文最大 72ch。用户消息比 agent 回复重一档。
- 管理页（环境 / Agent / 权限等）：标题 26px 加副标题；列表用无竖线表格（表头 1px 墨线、行 1px 淡线）；编辑用「左列表 + 右表单」的分栏框，外框 1px 墨线。
- tab 会增加：外壳必须能容纳更多 tab 而不改结构；新页面套用管理页的版式，不另起风格。

## 签名：序号标尺

对话页标题下方一条标尺，每个事件一格：普通格 8px 高灰墨；最新格 16px 高墨色（运行中为蓝色闪烁）；缺口格 16px 红色斜线填充，同步后逐格补成墨色。它是协议里"序号加缺口检测"（ADR-0005）的可见化，重连态由它和顶部同步条共同表达。新增状态展示时优先考虑能否用这条标尺表达，而不是新加徽章。

## 动效

丰富但自然，克制不抢戏。
- 缓动统一 `cubic-bezier(.16,1,.3,1)`（慢出）。页面进入 500ms 上浮 6px 淡入；消息进入 600ms 左滑 10px，兄弟项错开 80ms；hover 过渡 200 到 250ms。
- 进行中用 `steps(2)` 的硬闪烁（运行点、光标、最新格），不用呼吸渐变。
- 不确定进度用细条来回滑过（重连同步、工具运行中）。除此之外不做无限循环、不做跑马灯。
- 提示条出现用 `clip-path` 从左擦入。
- 必须尊重 `prefers-reduced-motion`：动画时长压到近 0，循环动画降为一次。

## 状态必须诚实

连接中断、补快照、排队中这类中间态要明确展示，不假装一切正常。
- 断线：顶栏连接点变红闪烁，标尺出现缺口格，页面顶部出现纸色底、墨线下划的同步条（不是整条实心红）。
- 排队中的消息：角色列写"排队中"（蓝），正文淡一档，下方小字"当前步骤结束后送达"。
- 工具调用卡片：头部显示工具名与状态（完成 绿 / 运行中 蓝）；运行中底部有一条蓝色滑动细线。
- 运行中的会话：删除键禁用，不隐藏。

## 弹窗（审批与提问共用一套）

- 居中，宽度 `min(460px, 92vw)`，1px 墨框，底部两个等宽按钮「拒绝」（红字）与「允许」，按钮之间 1px 墨线；hover 反白。
- 必须写明来源：哪个会话、哪个环境、要执行什么（等宽代码块）。
- 不可点遮罩或按 Esc 关闭，只能明确答复；先答先赢时由外部信号关闭。
- 打开时背景（顶栏、页面）`inert`，焦点落在"拒绝"上，关闭后焦点回到触发元素。
- 顶栏有常驻的红框「N 项待审批」按钮，可重新打开。

## 响应式（不做原生移动端）

桌面优先的响应式 Web，不做原生 App。移动端只保证三件事：对话、停止、答复审批。
- 900px 以下：会话列表收起，消息角色列改为上下排列，tab 栏可横向滚动且不换行，分栏表单变单列。
- 管理页在手机上能看能改即可，不追求舒适。
- 想要更像 App 的体验再加 PWA，不改变这条决定。

## 主题变量（预留整套替换的点位）

- 颜色、字体、圆角、边框粗细、遮罩模糊度全部走 CSS 变量，Tailwind 的主题配置映射到这些变量；组件只用语义名（`bg-panel`、`text-mute`、`border-line`），不用具体色值。
- 变量定义在 `:root`，替换整套风格时用 `[data-theme="<name>"]` 覆盖。
- 变量只能换"皮"；换到结构不同的风格（如磨砂悬浮卡片）时，少量组件需要按主题写覆盖样式。现在不做主题切换器，也不为未来主题提前做抽象。

## 可访问性基线

正文对比度不低于 4.5:1；焦点环 2px 蓝（`outline-offset: -2px`）；全部可键盘操作；`<button>` 用真按钮；图标按钮要有可访问名称；标尺这类纯展示图形用 `role="img"` 加说明性 `aria-label`，状态变化时更新。

## 不要做

- 不加阴影、渐变、玻璃、霓虹；不用拟物。
- 不用红色之外的颜色表达"危险"；不让红色同时出现在三处以上无关的地方。
- 不为了填满空白而加装饰；留白是结构的一部分。
- 不加主题切换器、不预设暗色主题（暂不需要）。
- 不在组件里写死色值、字体名、魔法数字尺寸；新增尺寸先看能否复用现有间距节奏（4 / 8 / 12 / 16 / 20 / 24 / 28）。
