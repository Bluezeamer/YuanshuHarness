# 元枢 WebUI 风格：奶油纸 + 珊瑚陶土

先看 [assets/reference.html](assets/reference.html)（可直接用浏览器打开的静态成品，四个 tab、重连态、审批弹窗都能切换），它是风格的唯一视觉真相；本文是它的规则化说明。两者冲突时以 reference.html 为准，并回头修本文。工作区（pane 布局、会话 rail）的高保真原型是 `tmp/mock-proto`，配色与字体取向以它为准。

## 一句话

一块按网格排版的控制台：奶油纸底、暖白卡片、1px 发丝线、单一珊瑚强调色，把事件序号当作可见的标尺。拒绝"灰底加一个强调色"的默认后台。顶栏 54px，品牌是 24px 珊瑚圆角方块加字。

用户是单人开发者，长时间盯着看，中文界面，信息密度偏高。装饰让位于信息。

## 颜色：各司其职

只用语义变量，组件里不写死色值（见「主题变量」）。色值用 oklch。

| 变量 | 默认值 | 角色 |
|---|---|---|
| `--bg` | `oklch(97% .012 85)` | 页面底，奶油纸 |
| `--panel` | `oklch(99.5% .004 85)` | 卡片、顶栏、输入栏（mock 里叫 surface） |
| `--ink` | `oklch(28% .02 70)` | 主文字、结构（mock 里叫 fg） |
| `--mute` | `oklch(52% .02 75)` | 次要文字（对比度满足 4.5:1） |
| `--line` / `--line2` | `oklch(86% .016 80)` / `oklch(91% .012 80)` | 外框、分隔线 / 更淡的行分隔 |
| `--accent` / `--accent-deep` / `--accent-soft` | 珊瑚陶土 | **焦点/你**：选中、焦点环、主按钮、你的操作 |
| `--ok` / `--ok-ink` / `--ok-soft` | 绿 | **活着**：运行中、在线、完成。`--ok` 只做点、线、环，文字用 `--ok-ink` |
| `--warn` / `--warn-ink` / `--warn-soft` | 琥珀 | 等待、暂停 |
| `--danger` / `--danger-soft` | 红 | 需要人介入：停止、拒绝、失败、序号缺口、待审批 |

规则：
- 绿 = 状态语义（"活着"），珊瑚 = 选择语义（"焦点/你"），分工刻意，不要混用。选中的 rail 项、当前 tab、焦点环用珊瑚；运行点、在线点用绿。
- 红色出现就意味着有事要人处理，不拿来装饰。
- 状态不只靠颜色：同时给文字或形状（缺口是斜线格，运行中有闪烁，完成有文字"完成"）。
- accent、ok、warn 的本色压在 bg 上不足 4.5:1，只做点、线、环、底；文字与实心按钮底用 `-deep` / `-ink`（tokens.test.ts 守这条）。

## 字体：系统字体 + mono 双轨

| 变量 | 用途 |
|---|---|
| `--font-sans` | 阅读面：界面正文与标题，系统字体栈（-apple-system、PingFang SC、Microsoft YaHei 等） |
| `--font-mono` | 数据面：代码、命令、事件序号、地址、数字列；开启 `tabular-nums` |

不引入网络字体。字号：正文 13.5px/1.55；次要 12 到 12.5px；页面标题 22 到 26px，粗体 700；对话中用户消息 16px/600。组件里不直接写字体名。

## 形与线

- 卡片与弹层用圆角：`--radius` 10px（卡片、按钮、输入框）、`--radius-lg` 14px（弹窗、大面板）；胶囊标签 999px；状态点是圆。
- 层次靠 1px 发丝线加轻阴影：`--shadow-1`（卡片）、`--shadow-2`（悬浮层、弹窗）。无渐变、无玻璃、无霓虹。
- 唯一的模糊：审批弹窗遮罩 `backdrop-filter: blur(3px)`。

## 布局

- 外壳：顶栏（品牌、topnav、右侧连接状态）；topnav 当前项用 `--accent-soft` 底加 `--accent-deep` 字。
- 对话页：左栏会话 rail；右侧标题行、序号标尺、消息流、底部输入栏（发送、运行中出现红色"停止"）。
- 消息流：左侧 72px 角色列（用户 / 恒侍 / 排队中），正文最大 72ch。用户消息比 agent 回复重一档。
- 管理页：标题 26px 加副标题；列表用无竖线表格（表头 1px 线、行 1px 淡线）；编辑用「左列表 + 右表单」的分栏卡片。
- 工作区：自建分割树 + 可拖拽 pane（见 ADR-0027），pane 头与 tab 栏的结构沿用 mock。
- 间距节奏 4 / 8 / 12 / 16 / 20 / 24 / 28，新页面套用管理页版式，不另起风格。

## 签名：序号标尺

对话页标题下方一条标尺，每个事件一格：普通格 8px 高淡线色；最新格 16px 高墨色（运行中为绿色闪烁）；缺口格 16px 红色斜线填充，同步后逐格补成墨色。它是协议里"序号加缺口检测"（ADR-0005）的可见化，重连态由它和顶部同步条共同表达。新增状态展示时优先考虑能否用这条标尺表达，而不是新加徽章。

## 动效

丰富但自然，克制不抢戏。
- 缓动统一 `cubic-bezier(.16,1,.3,1)`（慢出）。页面进入 500ms 上浮 6px 淡入；消息进入 600ms 左滑 10px，兄弟项错开 80ms；hover 过渡 200 到 250ms。
- 进行中用 `steps(2)` 的硬闪烁（运行点、光标、最新格），不用呼吸渐变。
- 不确定进度用细条来回滑过（重连同步、工具运行中）。除此之外不做无限循环、不做跑马灯。
- 提示条出现用 `clip-path` 从左擦入。
- 必须尊重 `prefers-reduced-motion`：动画时长压到近 0，循环动画降为一次。

## 状态必须诚实

连接中断、补快照、排队中这类中间态要明确展示，不假装一切正常。
- 断线：顶栏连接点变红闪烁，标尺出现缺口格，页面顶部出现同步条（纸色底、细线下划，不是整条实心红）。
- 排队中的消息：角色列写"排队中"（珊瑚深色），正文淡一档，下方小字"当前步骤结束后送达"。
- 工具调用卡片：头部显示工具名与状态（完成 绿 / 运行中 灰）；运行中底部有一条绿色滑动细线。
- 运行中的会话：删除键禁用，不隐藏。

## 弹窗（审批与提问共用一套）

- 居中，宽度 `min(460px,92vw)`，圆角卡片加 `--shadow-2`，底部两个等宽按钮「拒绝」（红字）与「允许」，按钮之间 1px 淡线；hover 分别淡红底、淡珊瑚底。
- 必须写明来源：哪个会话、哪个环境、要执行什么（等宽代码块）。
- 不可点遮罩或按 Esc 关闭，只能明确答复；先答先赢时由外部信号关闭。
- 打开时背景（顶栏、页面）`inert`，焦点落在"拒绝"上，关闭后焦点回到触发元素。
- 顶栏有常驻的红框「N 项待审批」按钮，可重新打开。

## 响应式（不做原生移动端）

桌面优先的响应式 Web，不做原生 App。移动端只保证三件事：对话、停止、答复审批。
- 900px 以下：会话列表收起，消息角色列改为上下排列，tab 栏可横向滚动且不换行，分栏表单变单列。
- 管理页在手机上能看能改即可，不追求舒适。

## 主题变量（预留整套替换的点位）

- 颜色、字体、圆角、阴影、遮罩模糊度全部走 CSS 变量，Tailwind 的主题配置映射到这些变量；组件只用语义名（`bg-panel`、`text-mute`、`border-line`），不用具体色值。
- 变量定义在 `:root`，替换整套风格时用 `[data-theme="<name>"]` 覆盖。mock 里没有暗色，这里也不预设；不做主题切换器。

## 可访问性基线

正文对比度不低于 4.5:1；焦点环 2px 珊瑚（`outline-offset: 2px`）；全部可键盘操作；`<button>` 用真按钮；图标按钮要有可访问名称；标尺这类纯展示图形用 `role="img"` 加说明性 `aria-label`，状态变化时更新。

## 不要做

- 不加玻璃、霓虹；不用拟物；渐变只有顶栏底一处（surface 到 13% 珊瑚，对齐 mock）；阴影只用 `--shadow-1/2`。
- 不用红色之外的颜色表达"危险"；不让红色同时出现在三处以上无关的地方。
- 不拿绿色做选中、不拿珊瑚做运行状态。
- 不为了填满空白而加装饰；留白是结构的一部分。
- 不在组件里写死色值、字体名、魔法数字尺寸；新增尺寸先看能否复用现有间距节奏。
