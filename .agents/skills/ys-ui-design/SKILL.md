视觉系统**已经定了**，这里的任务是在它里面把事做对，不是再设计一套。本文放红线与速查，细则在 `references/`，按要做的事读：

## 守卫拦不住的红线

1. **不发明新东西**：不加新颜色、新字体、新圆角、新字样；在现有系统里把事做对，不另起一套风格。
2. **颜色**：近白冷灰；**同屏只有一个墨色实心按钮**；蓝只给聚焦环、选中态、链接；红 / 琥珀 / 绿只用于字、点、描边，**不铺底**（唯一的淡底是选中态的 `--accent-bg`）。
3. **分区靠底色不靠线框**：侧栏 `--side`、主区 `--surface`，之间不画线；线只出现在列表行之间、表格行之间、输入控件、卡片本体、主从页的一条竖线、页签条下一条线、区块小标题下一条线。
4. **字样**：只选角色类；选中态不改字重（只改颜色和底色）；等宽字只给英文 / 数字 / 路径，中英混排（如「2 分钟」）拆成两段；容器里的文字离边至少 8px。
5. **界面不写死平台符号**：不出现 ⌘ ⇧ ⌥ ⌃，写 `Ctrl+N` 这类平台中立文字（可用 `Kbd` 分键）。
6. **平时极简**（X05）：行上只放名字、一行副标题、一个状态；操作悬停 / 聚焦才出现，破坏性操作进菜单再确认；详情放悬停卡片（只读、不发请求）。**入口要带文字**：列表头 / 组头的菜单不能只放「···」图标，要有带文字的入口（如「批量设置」）。
7. **设置显式保存**（X06）：设置进草稿、保存条提交；动作（登录、测试、删除、弹窗自带提交）立即执行并弹提示；切对象 / 切页签有离开保护。
8. **页面左缘对齐**（X04）：页签文字、搜索框、列表行、列表页内容同一个 x（`--st-gutter` 24）；详情列最宽 720 居中。
9. **不用浏览器原生弹窗**（`confirm` / `alert` / `prompt`），用 `Modal` / `ConfirmDialog` / 行内提示。
10. **动效**：只动透明度和 ≤6px 位移，140–260ms，统一缓动，`prefers-reduced-motion` 下关闭。
11. 注释和字符串里别写 `#` 加 3–8 个十六进制字符的串（如 `#0042`、`#fff`），色值守卫会当成颜色。

## 看过才算

- 视觉改动要出实际界面自己看：跑 `scripts/verify-*.mjs` 存截图再读图（怎么存见 `ys-delivery`）；截图前等动画与悬停卡片稳定。
- **滚动与布局必须在真浏览器里量**，jsdom 与截图都测不出。设置页的 `.st-main` 是 `overflow: hidden`：新页面根容器要 `flex: 1 1 auto; min-height: 0`，需要滚的栏各自 `overflow-y: auto`；造够长的数据，量滚轮前后 `scrollTop`、最底下的控件能否进视口。
