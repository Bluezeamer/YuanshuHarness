# 视觉语言

颜色、形、控件、动效的统一约定。文字见 `typography.md`；交互标准见 `interaction.md`。令牌都在 `packages/web/src/ui/tokens.css`，**业务代码只用令牌，不写字面值**。

## 1. 总纲

近白冷灰底 + 墨黑做结构强调 + 少量蓝做交互强调。层次靠灰度和细线，不靠卡片套卡片，也不靠阴影。不必要的信息密度不该有：不知道给谁看的信息不呈现；按钮不一次性全部露出，悬停或聚焦才出现。不可避免高密度的场景（工作台、数据面板）参照 VS Code 与数据后台，用细线和灰度分层。

## 2. 颜色

三层面：**内容面**（白）、**侧栏 / 次级面**（极浅灰）、**悬停 / 当前项**（浅灰）。不再有第四层。

| 用途 | 令牌（取值） | 规则 |
|---|---|---|
| 墨 `--ink` | #18181b | **主按钮、当前页签顶线、发送键、品牌标记**：结构上的强调。**同屏只有一个墨色实心按钮** |
| 蓝 `--accent` | #2563eb（文字 #1d4ed8，浅底 #eff4ff） | **只给聚焦环、选中态、链接**：交互上的强调。不做主按钮、不铺大面积 |
| 红 `--danger` | #dc2626 | **只用在小面积**：字、点、描边。不铺底，没有 `--danger-soft` 这类淡红底 |
| 琥珀 `--warn` | #d97706（文字 #b45309） | 待处理 |
| 绿 `--ok` | #16a34a（文字 #15803d） | 执行中、成功 |
| 字 | #18181b / #52525b / #6a6a74 | 正文 / 次要 / 弱；弱字与图标分开：纯图标另用 #8b8b95，文字不得用 |

- **文件类型图标自带一套色板**（`--ci-*`）：这是图标自己的颜色，不是语义色，只用在文件类型图标上，不用于文字、按钮或状态。
- **语义色不铺底**，只用于字、点、描边。唯一例外是「选中 / 聚焦」的极浅蓝底（`--accent-bg`），不用于告警。
- **对比度**：弱字在白底 ≥ 5:1，在悬停底与当前项底 ≥ 4.5:1；纯图标 ≥ 3:1。
- 窗口色相轮 `--h1…h6` 给窗格主机色与分组色借用。语法高亮色沿用语义色派生。
- 强调色是蓝，想换只改令牌：强调色只出现在小面积，换色成本很低。
- **品牌标记**（纯墨的一笔倾斜椭圆轨道：笔头重、尾部收尖散成飞白、中心留空）：只有一套几何，16px 到 512px 都用它。`packages/web/public/` 下：名称左侧用 `mark.svg`（28px，`<img>` 直接引用）；浏览器标签用 `favicon.svg`（标记铺满瓷砖）；PWA 用 `icon.svg` / `icon-maskable.svg`；另外横排 logo 在 `docs/brand/logo*.svg`（宋体「元枢」+ YUANSHU HARNESS）。SVG 全由 `scripts/brand/gen.mjs` 生成，要改就改脚本再跑，别手改 SVG。不另造品牌色。**标记在自己的画布里居中，不做光学上移**（上移后会像浮在文字上方；斜弧的墨偏左下，与外接框居中的中文基线读起来是同一条水平线）。**验标记一律按 1 倍像素、逐像素放大看**（2 倍屏的预览会骗人；飞白在 16px 下只剩一层淡灰，这是可接受的）。

## 3. 形与间距：刻度

**四张刻度表。选了刻度就不要再写刻度外的值**：新增需求先问「能不能归到已有的一档」。守卫的白名单在 `packages/web/src/test/guard/scan.ts`。

| 间距（`gap` / `padding` / `margin`） | 值 | 用在哪 |
|---|---|---|
| 4 | 4 | 图标与文字微调、相邻图标按钮 |
| 6 | 6 | 胶囊内、紧凑的行内元素 |
| **8** | 8 | **默认**：控件与列表项的内边距、行内元素间距 |
| 12 | 12 | 卡片内边距、摘要行左右、区块里的段间 |
| 16 | 16 | 面板内边距、卡片之间、字段之间 |
| 24 | 24 | 弹窗内边距、区块之间 |
| 32 | 32 | 大区块之间 |
| 48 | 48 | 页面顶部、空状态留白 |

| 高度（控件与行） | 值 | 用在哪 |
|---|---|---|
| 20 | 20 | 胶囊、键帽 |
| 28 | 28 | **紧凑行**：工作台里的会话行、文件行；图标按钮；状态栏 |
| 32 | 32 | 控件默认、设置页的行、左轨工作区行 |
| 36 | 36 | 弹窗里的输入与按钮、工作台标签栏、步骤行 |
| 40 | 40 | 设置页页签 |
| 44 | 44 | 弹窗里的摘要行、左轨顶栏与底栏 |

| 圆角 | 值 | 用在哪 |
|---|---|---|
| 小 | 6 | 行内代码、标签、分段里的指示块、聊天气泡的尖角 |
| 控件 | 8 | 输入、按钮、分段容器、悬停行 |
| 卡片 | 12 | 卡片、下拉菜单、步骤分组 |
| 弹层 | 14 | 弹窗、输入栏（composer） |
| 胶囊 / 圆 | 999 | 胶囊、圆形按钮、状态点 |

| 层级（`z-index`） | 值 | 用在哪 |
|---|---|---|
| 0 | 0 | 普通内容；**组件内部的局部叠放（如分段指示块在按钮之下）用 0 / 1，不算全局层级** |
| 1 | 10 | 粘性栏、分隔线手柄 |
| 2 | 20 | 悬停卡片、局部浮层 |
| 3 | 30 | 全屏层与弹窗：设置页、弹窗与遮罩（同一层，后挂载的在上） |
| 4 | 40 | 下拉与菜单（都 portal 到 `body`，必须盖在弹窗上）、提示条、传输条、拖拽幽灵 |

**不归刻度管的两类**（否则表会被一次性数字塞满）：
- **组件自身的固有尺寸**：状态点 6 / 8px、细进度条 2 / 3px、分隔线 1px、开关与滑块的拨块 16px、品牌标记、内联代码的 1px 垂直内边距。它们是「这个东西长多大」，不是间距。
- **布局级数字**：页面左右留白、最大宽度（960）、左轨宽（252，收起 62）、弹窗宽（560）、卡片与输入区的最小高度。每个只在对应布局里写一次。

其余规则：
- **容器里的文字不得贴边**：带边框、带底色的容器，文字到边至少 8px，通常 12–16px（整行贴满容器的页签条、列表分隔行是结构，不算）。
- 阴影三档：小（卡片静止）、中（卡片悬停）、弹层。**分层主要靠灰度和细线，不靠阴影**。
- **嵌套圆角**：外层 = 内层 + 内边距 的近似；分段容器 8、里面的指示块 6，卡片 12、里面的行 8。

## 4. 控件：全站只有一套

下拉、输入、按钮、分段、开关、滑块、页签，**全部自绘，不使用浏览器原生控件**；同一种控件只有一种长相。

- **按钮**：墨色实心（主）/ 描边（次）/ 无边框（幽灵）。
- **下拉**：自绘菜单，当前项带勾，展开时箭头翻转，菜单淡入并有 4px 位移；菜单宽度不小于触发器。
- **分段**：滑动的白色指示块；不可用项半透明，悬停给出原因。
- **页签**：滑动的墨色下划线。
- **悬停才出现的操作**：卡片上的复制 / 删除、会话行的「⋯」、文件行的操作，平时不显示，**悬停或键盘聚焦时出现**（不能只靠鼠标）；不可用的操作置灰并说明原因（如「被 N 个会话引用，不能删除」）。
- **折叠成摘要行**：次要设置默认只露一行「名称 + 值 + 灰色的『· 跟随默认』」，悬停出现箭头，点进去展开。
- **工具调用折叠**：对话里连续的工具调用折成一行「读取了 6 个文件」，出错的才展开；错误用红点和红字，不用红底。
- **状态点**：执行中 = 绿色脉动；待处理 = 琥珀；新结果 = 蓝点；出错 = 红点。
- **读条与进度条的空轨**用 `--line-strong`：用更浅的灰（`--active`、`--line`）会读不出「还剩多少」；厚度不用改（`ReadBar` 3px、`ProgressBar` 2px）。
- **临时标签**：斜体标题。
- **窗格标签条的标题宽度固定**：每个标签的标题区同宽，超出省略，完整标题放 `title`；增删、改名、切换标签时整条不抖。宽度数值只写在 `ui/styles/nav.css` 的 `.u-strip-title` 一处，觉得窄 / 宽改这一个数。关闭键悬停、聚焦或当前标签才出现。组件是 `ui/TabStrip`。

## 5. 动效

只动透明度和不超过 6px 的位移；过渡 140–260ms，缓动统一一条；页面入场错开 28ms 逐项出现；`prefers-reduced-motion` 下全部关闭。滑动指示（分段、页签）、下拉展开、卡片悬停上浮 1px、状态点脉动是用到动效的几处。

## 6. 分区靠底色，不靠线框

- **整体分区靠底色**：侧栏 / 导航用 `--side`，主区用 `--surface`，两者之间不画线；不画包住整页的圆角外框。
- **线只出现在这几处**：列表行之间、表格行之间、输入控件、卡片本体、主从页左列表与详情之间的一条竖线、页签条下的一条线、区块小标题下的一条线。
- **导航项**：深字（`--fg`），悬停 `--hover`，当前项 `--active` 底；不描边、不加左侧黑线、不用灰字（灰字压在浅灰底上读不清）。
- **平铺布局**（工作区窗格）：格子之间只有一条 1px 细线，不画外框、不做卡片和圆角；窗格头用标签条版式，窗口条用另一种形（浅灰胶囊），两层标签条一眼要分得开。一个格子属于哪台主机，用「色点 + 主机名 + 窗格头底边一道主机色线」表示；窄到放不下就只留色点。常驻的操作提示不要，拖拽时才出现。
- **标签内容区的工具条永远只有一行**（36 高：文件管理器、预览、浏览器、执行体）：选择、未保存这类状态在同一行里换内容或才出现，不增行、列表不跳；窄窗格按窗格宽度（`@container pane`）先把次要按钮的字收成只剩图标，再不够就把次要动作收进末尾的「…」菜单（菜单是完整的动作清单），不换行；阈值要实测（每档地址这类主体至少留 100px），别估。终端平时没有条，只有异常才浮出提示或说明卡。主机、目录这类窗格头与标签提示里已有的信息，不在条里重复。
- **没有顶栏**：「返回」放导航最上面，页面名只靠导航高亮表达；保存状态用保存条与右下角提示（`interaction.md` X06）。
- 设置壳与页面留白的规则见 `interaction.md` X04，组件见 `ys-ui-build` 的 `components.md`。
