# 交互标准

编号稳定，只追加，不复用、不重排；代码注释里按编号引用（如 X06）。X01、X02 是产品行为而不是写界面的方式，不在本文展开：X01 单击 = 临时查看、双击 = 固定新开、拖拽 = 明确的空间操作；X02 跟随上一层、可覆盖的设置要显示值的来源，并提供「恢复跟随」（出处 `docs/model/workspace.md` §7）。

## X03 界面不写死平台符号

快捷键的显示不写死 ⌘ ⇧ ⌥ ⌃。按键匹配已区分平台（`app/shell/shortcuts.ts` 的 `isMac`），问题只在显示：新写的界面文字一律写 `Ctrl+N` 这类平台中立的写法，按键可以用 `Kbd` 分开画。目标是代码里只写逻辑键（如 `mod+shift+n`）、由唯一的渲染函数按平台输出（macOS 显示 ⌘⇧N，其余显示 Ctrl+Shift+N），这个函数还没有，见 `docs/model/layout.md` §8 的「仍待做」。

## X04 页面左缘对齐

设置页（以及以后所有「页签 + 内容」的次级页）里，**页签文字、列表的搜索框与行、列表页的内容，左缘落在同一个 x 上**，这个值叫「页面留白」，取 24，只在设置壳里写一次（`--st-gutter`）。

- 页签条的线通栏，文字缩进留白；不居中、不随屏宽漂移。
- 主从页的左列表宽 = 240 + 2 × 留白，列表内容离栏边留白，所以搜索框与页签文字同 x。
- 列表页（卡片、表格）内容从留白起铺满，不再各设最大宽度。
- 详情与单栏设置页的列最宽 720、居中；它不要求和页签同 x，因为它在滚动区里自成一栏。
- 组件：`PageTabs`、`RailList`；新页面直接用，不自己写页签与列表栏的内边距。

## X05 列表行：平时极简，悬停出操作与详情

页内左列表（供应商、变量、连接……）与左轨的行遵守同一套约定：

- **行上只放最少的信息**：名字、一行副标题、一个状态（点或几个字）。长描述、完整路径、元数据不进行里。
- **操作浮现**：悬停或键盘聚焦时，状态位换成「⋯」按钮，点开是菜单；破坏性操作进菜单，再弹确认框。平时不露出任何按钮。机制是 `ListRow` 的 `actions`（`u-reveal`）。
- **详情卡片**：悬停停留约 450ms 或键盘聚焦时，在行的右侧浮出一张**只读**卡片（`ListRow` 的 `peek`），放行里没有的信息：描述全文、所属、策略、有效期、最近活动等。
  - 卡片只读：没有按钮、没有链接、不接鼠标（`pointer-events: none`），能操作的东西只在「⋯」菜单里。
  - 刚有卡片收起后的 300ms 内，邻近行立即出现，扫过一排行时是连贯的；按下鼠标后到指针离开前不再弹，免得盖住刚打开的菜单；Esc、滚动、离开都收起。
  - 只用行手头已有的数据，**悬停时不发请求**；右侧放不下翻到左侧，纵向夹在视口内。
  - 只用于列表行，不用于表格行与页内卡片（它们靠列或卡片本身展示信息）。
  - 带 `peek` 的行不再挂原生 `title`，免得气泡叠在卡片上。
- 左轨收起态（62px）的会话列表浮层是另一种东西——它可点、可操作，是「收起后的展开替身」，不受「只读」约束，只共用卡片外壳样式。

## X06 设置显式保存

设置页里的**设置**一律「改了进草稿，点保存才落库」，**操作**立即执行：

- **设置**：页面上直接编辑的值（文本框、下拉、开关、数字、勾选）。改了就在滚动区底部浮出保存条（「有未保存的修改」+ 放弃 / 保存），没有修改时不显示、不占位；Ctrl+S 同样保存。
- **操作**：动词——登录、测试连接、从端点获取、删除、轮换、显示值、复制，以及弹窗里自带提交按钮的添加 / 编辑。立即执行，结果用右下角提示，不进草稿。
- **反馈**：保存成功弹绿色提示「已保存」；失败弹红色提示并**保留草稿**，字段级的错误仍显示在字段下面。顶栏不再有保存状态。
- **离开保护**：有未保存的修改时，切换编辑对象、切页签、点设置导航、返回工作区，都先问「保存 / 放弃修改 / 取消」；只有一处对话框，在设置壳里。
- 组件：`useDraft`、`SaveBar`、`useLeaveGuard` / `useBindDirty`。
- **本机设置不进草稿**：界面字号这类只存浏览器本地、即时生效的项，直接生效，不进保存条。
- **保存会重写磁盘文件时**（产品里的全局 AGENTS.md 的生效版本）：文件被人手改过就不替用户决定——服务端拒绝并要求确认，界面弹窗给「直接覆盖 / 另存为新版本再继续 / 取消」，保存草稿保留。

## X07 卡片列表页：点开编辑页，整页替换

「卡片网格 → 点开一份 → 编辑」的页（Agent、模式、两份 AGENTS.md、附加提示词）遵守同一套（这里的 AGENTS.md 指产品里的预设）：

- **列表页**：页签条下面是搜索框与主按钮，再下面是卡片网格；卡片只放名字、状态标记、一句描述、一行统计；操作进悬停的「⋯」菜单，不露按钮（X05）。组件 `CardGrid`。
- **编辑页整页替换**，连页签条一起换掉；页头左上是返回箭头，然后是名字、一行说明，右侧是这份东西的主操作（激活、复制）。内容超过一屏的有自己的页签（提示词 / 能力 / 设定），只有提示词的没有。返回箭头也过离开保护。
- **点开的是页，不是弹窗**；只有「卡片库里的一张卡片」这种体量小、不需要上下文的才用悬浮窗（`FormDialog`，不满屏）。
- **同一时间只有一个生效的东西**（全局 AGENTS.md 版本、全局附加提示词版本）：卡片上标「生效中」，生效中的不能删（菜单项置灰并说明）；激活在卡片菜单与编辑页页头都有。
- **左侧导航列用来分类**（卡片库的分组）：分组能在列表底部新建；分组行悬停的「⋯」里有删除（只有空分组能删，非空置灰并写明张数）。分组下的内容在右边铺成网格。

## X08 悬停展开的区域：整块离开才收起

可交互的悬停展开件（左缘导航、右侧状态的竖排标签与它展开的卡片）：

- **展开的是一整块区域**（触发条 + 展开的卡片 + 它们之间的空隙），**鼠标完全离开整块才收起**，不是离开触发的那一小点就收。触发条与卡片之间留空隙时，用透明的桥（`padding`）把两者连成一块，鼠标穿过空隙不收。
- 展开时触发条里的东西**原地不动**，文字统一对齐在同一列、位置不跳；强调靠线条长短、底色、文字深浅，不靠位移。
- 键盘聚焦也展开，焦点离开整块才收。
- 只读的悬停详情卡（X05 的 `HoverCard`）不适用：它不可交互，指针一离开就收。
- 窄的地方要收起时，用竖排的**文字标签**；无字的小圆点、没有合适含义的图标认不出来。
