# 字样角色

**字样角色 = 一整套字样**（大小、字重、字体族、行高一起定）。组件只选角色类，不再各写这四个属性。本文只管文字；颜色、控件、动效见 `visual-language.md`。

## 1. 角色清单

名字只描述文字承担的**功能**，不描述长相；每个都带一个判断问法。

**外壳族**（固定大小，不随字号设置缩放；界面本身的文字）

| 角色（类名） | 大小 / 字重 / 行高 | 判断：这段字是不是它？ |
|---|---|---|
| 页标题 `t-page` | 20 / 600 / 28 | 一个页面最上面那个大标题 |
| 区块标题 `t-block` | 16 / 600 / 24 | 弹窗或页面里某一块的标题 |
| 分组名 `t-group` | 12 / 600 / 18 | 一组设置上面的小标题（「新会话」「权限」） |
| 条目名 `t-entry` | 13 / 500 / 20 | 一行里**被点、被选、被读的那个名字**：字段名、按钮文字、会话名、文件名 |
| 普通字 `t-plain` | 13 / 400 / 20 | 其余的普通文字：输入框里的内容、摘要行的值 |
| 辅助字 `t-aux` | 12 / 400 / 18 | 比条目名低一级的解释：字段下的说明、状态栏、胶囊里的字、会话副标题 |
| 等宽字 `t-mono` | 12 / 400 / 18，mono | 路径、数字、耗时、快捷键 |

**内容族**（随字号设置缩放；要长时间读的文字）

| 角色（类名） | 大小 / 字重 / 行高 | 用在哪 |
|---|---|---|
| 阅读字 `t-read` | 基准（默认 16）/ 400 / 1.72 | 对话正文、用户输入的消息 |
| 文档字 `t-doc` | 基准（默认 16）/ 400 / 1.72，标题按文档层级（h1–h6 = 1.625 / 1.3125 / 1.125 / 1 / 0.875 倍）、表格 0.9 倍 | **Markdown 渲染出来的 HTML 正文**：对话、文件预览、笔记、画布卡片 |
| 代码字 `t-code` | 基准 × 0.875（默认 14）/ 400 / 1.6，mono | 代码块、工具输出、命令参数、文件预览 |

共 **10 种，不再加**；真有新需求先问「能不能归到已有的某一种」。
**最容易混的是「条目名」和「普通字」**：一行里有没有「点它会发生事」，有就是条目名。

## 2. 规则

- **等宽字只给英文、数字、路径**。中文字符在等宽字体里不等宽，所以中英混排的（如「2 分钟」「刚刚」）拆成两段：数字用等宽字，中文用辅助字，不能一个标签里混。
- **胶囊里的字用辅助字**，靠胶囊的底色区分，不靠字重。
- **品牌名不单独占角色**，直接用区块标题或条目名。
- 字重只用 400 / 500 / 600 三档；不用 650、700。
- **选中态不改字重，只改颜色与底色**：选中的页签、当前的导航项、当前的会话名都不变粗。改字重会让文字变宽、点击时抖一下；「选中」已有底色或下划线表达，字重是多余的第三重信号。
- **渲染出来的 HTML 正文**（Markdown：对话、文件预览、笔记、画布卡片）没法逐个元素加类：容器选 `t-doc`，同时加 `md-prose`（`features/markdown/prose.css`，间距、颜色、列表标记、引用、表格、代码块的外观；**四处共用这一份，别各写一份、也别用 CSS 补**）。为什么不借界面的字样：区块标题（16px）、分组名（12px）与正文（16px）几乎同大，借来给 h1–h6 用，层级就是扁的，所以文档单独有一档。容器自己只写布局（版心、内边距），不再写字号字重；外边距用 em（随字号设置缩放）。
- **列表里的名字想要普通字重**：`ListRow` 的 `label` 外层固定是条目名；在 `label` 里放一个 `<span class="t-plain">` 即可，不要在 CSS 里改 `font-weight`。
- **别靠标签的默认样式**：`<b>`、`<strong>`、`<h1>`…浏览器自带加粗与字号，会绕过角色。要强调用角色类或颜色。需要语义标题（弹窗标题、读屏用的页标题）时可以用 `<h1>`–`<h6>`，但必须同时带角色类（或 `sr-only`），长相由角色类给。
- **快捷键提示、git 状态字母这类小字也用等宽字**（12px），不另设更小更粗的一档；键帽靠边框、git 状态靠颜色区分。
- 字体族只有两个：无衬线（系统中文字体栈）和等宽；角色定义里写死，组件不选。项目不带网页字体。

## 3. 随字号设置缩放

用户的字号设置只影响**内容族**（阅读字、代码字），外壳族固定——避免「整体放大把左侧会话卡与标签栏撑胖」。

- 阅读字 = 字号设置的基准，默认 16px；代码字 = 基准 × 0.875，默认 14px。改默认只改 `app/fontSize.ts` 的 `BASE_DEFAULT` 一个常量。
- 运行时变量只有两个：`--fs-read`、`--fs-code`。`xterm` 画在 canvas 上不认 CSS 变量，订阅变更通知。
- 没有「元信息」档：路径、时间戳用等宽字（`t-mono`）或辅助字（`t-aux`），都是外壳族、固定大小。字号只能来自角色类。
- 用 JS 画字的两处（xterm、CodeMirror）是例外：字体与字号只能当选项传，值取自 `--font-mono` 与 `--fs-code`。

## 4. 实现位置

- 角色定义只写在 `packages/web/src/ui/type.css` 一处，每个角色一个类。
- 除该文件外，所有 CSS / TSX 里出现 `font-size`、`font-weight`、`font-family`、`line-height`（含内联 `style={{ fontSize }}`）都由 `src/design.guard.test.ts` 的 `type` 规则拦下。
