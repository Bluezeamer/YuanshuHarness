# Browser Verification: 统一弹窗与权限管理 WebUI
Date: 2026-10-18
Verifier: 待人工

> 范围：prompt-dialog R9、min-workspace R7、permission-rules R12、auto-review R8。组件测试已覆盖逻辑，此处只列需真实浏览器与真实 Server 确认的项。

## Setup
1. 起真实 Server（`vite.config` 代理 `/api` 到 `127.0.0.1:7420`），`cd packages/web && pnpm dev`，输入令牌进入。
2. 准备一个会触发审批的会话（规则审批档下让 agent 执行 bash），以及一个调用 `ask_user` 的会话。

## Checklist
- [ ] 审批弹窗出现在对应会话的 chat pane 内，pane 外（顶栏、其他 pane）不被遮挡、可操作。
- [ ] 弹窗展示工具名与命令/路径摘要，三个选项「允许 / 拒绝 / 允许并记住」，焦点默认在「拒绝」。
- [ ] 有倒计时（`剩余 m:ss`）且每秒递减；Esc、点遮罩都不关闭，也不等于拒绝。
- [ ] Tab/Shift+Tab 在弹窗内循环；弹窗后面的输入框不可聚焦（inert）；关闭后焦点回到原位置。
- [ ] 提问（input）可输入并回车提交，Shift+Enter 换行；输入法组合中回车不提交。
- [ ] 两个浏览器标签打开同一会话：一端答复后，另一端弹窗自动消失。
- [ ] 弹窗期间拖动 pane、切换 window 再切回：弹窗仍在；另一端答复后回来弹窗已消失。
- [ ] 刷新页面：待处理弹窗由快照补发。
- [ ] 点「允许并记住」后设置里能看到规则，删除后同类命令再次弹窗。
- [ ] 设置：新增（无效路径/重复路径提示）、改名、改档位、删除（有会话引用时提示）。
- [ ] 档位选「完全允许」出现红框风险提示，保存前二次确认；选「自动模式」文案含“拿不准会交给你决定”。
- [ ] 审核策略：保存、清除；超过 4000 字被限制。
- [ ] 新建会话可选工作区，创建后出现在会话列表。
- [ ] 900px 以下：设置的分栏变单列，弹窗宽度不溢出，移动端能答复审批。
- [ ] 开启 prefers-reduced-motion 后动画基本静止。
