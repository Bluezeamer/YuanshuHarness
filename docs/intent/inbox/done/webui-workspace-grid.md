 # WebUI 工作区布局 — 需求                                                        
                                                                                
 ### 目标                                                                       
                                                                                
 WebUI 从"单页对话窗口"升级为"多面板工作区"。打开即是一个高效的工作中枢，所有常 
 用面板同时可见、可交互，不需要在多个页面/应用间切换。                          
                                                                                
 ### 布局结构                                                                   
                                                                                
 - 页面顶部是一排 Tab，每个 Tab 代表一个独立工作区。                            
 - 每个 Tab 内部是网格布局，由若干面板（Pane）组成。                            
 - 面板可通过拖拽分割线调整大小，支持水平/垂直任意组合嵌套。                    
 - 布局状态持久化：刷新后恢复所有 Tab、面板及其尺寸。可存储设计的布局以便快速唤起预设   
                                                                                
 ### 面板类型                                                                   
                                                                                
 面板是内容无关的容器，具体内容由注册的"面板类型"决定。一期包含：               
                                                                                
 - chat — Agent 对话                                                            
 - filediscovery — 文件浏览/搜索                                                
 - terminal — 终端                                                              
 - file_preview — 文件内容预览                                                  
 - web_preview — 网页预览                                                       
                                                                                
 面板类型是可注册的：新增类型只需声明"我是什么、我渲染什么"，布局机制不需要任何 
 改动。后续扩展走同一通道。                                                     
                                                                                
 ### 交互                                                                       
                                                                                
 - 新建面板：在现有面板上分割（水平或垂直），选择要放的内容类型。               
 - 调整大小：拖拽面板之间的分割线。                                             
 - 跨 Tab 移动面板：将一个面板从当前 Tab 拖拽到另一个 Tab 中。                  
 - 关闭面板：移除单个面板。                                                     
 - Tab 管理：新建、关闭、重命名、切换。                                         
                                                                                
 ### 状态感知（高级，后期）                                                     
                                                                                
 同一 Tab 内、关联同一主机/环境的多个面板之间，可互相感知状态。例如：           
                                                                                
 - 在 file_preview 中选中了一段代码，chat 面板能知道并用于上下文。              
 - 在 terminal 中执行了命令，chat 面板能获取输出状态。                          
                                                                                
 一期只预留通信接口，不实现具体逻辑。                                           
                                                                                
 ### 预期效果                                                                   
                                                                                
 打开 WebUI → 看到自己的"工作台"：左边是 chat，右边上下分别是 terminal 和       
 file_preview，顶部 tab 还有另一个 tab 放着一组不同的面板组合。所有东西同时可见 
 、独立操作、互不阻塞。快捷键可快速切换焦点面板。这就是 Web 端的 tmux。
