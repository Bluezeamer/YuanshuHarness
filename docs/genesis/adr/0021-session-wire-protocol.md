# ADR-0021: 会话线上协议：端点、信封、命令与缺口处理

状态：已定稿
日期：2026-10-17
可逆性：难逆
取代：无
被取代：——
引用入口：ARCHITECTURE「技术选型」客户端协议一行；ROADMAP 第 3 条

## 背景
[ADR-0005](0005-client-protocol.md) 只定了语义（序号、最近窗口、排队、先答先赢），[ADR-0020](0020-transport-websocket.md) 定了传输层。
所有客户端（WebUI、命令行、TUI、IM 网关）都依赖这里的端点、字段名与事件类型，一旦发布就成了对外契约，所以难逆。
pi 的事件没有序号，其事件类型随 SDK 版本变化（[ADR-0001](0001-pi-sdk-no-fork.md) 要求不 fork 也要能升级）。

## 候选方案
### 事件类型：透传 pi 的事件，还是自己命名
- A. 透传 pi 事件。代价：SDK 升级改了事件，所有客户端跟着坏。
- B. Server 自己定义一套薄的事件类型，由 pi 事件映射而来。代价：多一层映射要维护；pi 新增事件默认不会到达客户端。

### 会话标识
- A. 顺序整数。代价：暴露数量，且日后多存储时易冲突。
- B. 不透明字符串（UUIDv7）。代价：不便手输。

## 决定
事件类型选 B，会话标识选 B（UUIDv7，客户端当作不透明字符串，不解析）。

**端点**（版本号在路径里，破坏性变更升 `v2`）
- `POST /api/v1/sessions` 创建，`GET /api/v1/sessions` 列表，`GET /api/v1/sessions/:id` 查询。
- `GET /api/v1/sessions/:id/stream`（升级为 WebSocket）：该会话的事件与命令。
- 健康端点 `/healthz` 不变（[ADR-0018](0018-startup-params-and-health-endpoint.md)）。

**Server 到客户端的信封**：`{ "session": "<id>", "seq": <整数>, "ts": "<ISO 8601>", "type": "<类型>", "data": { ... } }`
- `seq` 是该会话内的单调递增整数，仅用于衔接与缺口检测（[ADR-0005](0005-client-protocol.md)）。
- 连接建立后的第一条消息是 `snapshot`：最近窗口的消息、当前执行步骤、排队中的消息，及快照对应的 `seq`。之后的事件 `seq` 从快照的下一个值起连续。
- 事件类型用点号分层小写命名（例如 `message.delta`、`tool.started`、`queue.updated`）。具体清单留给 spec；客户端遇到不认识的类型必须忽略，Server 不得改变已发布类型的含义。
- 弹窗相关类型本期不实现，命名空间 `prompt.*` 预留。

**客户端到 Server 的命令**：`{ "id": "<客户端生成>", "type": "<类型>", ... }`
- 本期命令：`send_message`、`stop`、`resync`。
- Server 用 `{ "type": "ack", "id": "<原 id>", "ok": true }` 或带 `error` 的失败形式回应；`ack` 不占 `seq`。
- `send_message` 在会话运行中时进入排队，由 `queue.updated` 事件通知所有客户端。
- `stop` 对任一客户端有效。

**缺口处理**：客户端发现 `seq` 不连续，发 `resync`，Server 回一条新的 `snapshot`，之后事件从其 `seq` 的下一个值续上。窗口之外的历史按需用 REST 拉取（路径随持久化一块定）。

## 理由
- 薄事件层把 SDK 的变动挡在 Server 里，客户端只依赖我们承诺的类型。
- 不透明标识让存储实现可以更换而不影响客户端。
- 路径带版本号，让将来的破坏性变更有出路，不必让旧客户端同时失效。
- `resync` 复用快照，不需要另一条恢复路径，行为只有一种。
- 忽略未知类型的规则让 Server 可以只增不改地扩展事件。

## 影响
- spec 要定：事件类型清单与各自的 `data` 形状；最近窗口的条数；错误码；心跳间隔与超时。
- 任何新增的 pi 事件要显式加映射才会到达客户端；SDK 升级时契约测试要覆盖映射。
- 已发布的字段名与类型含义只增不改，改动须升 `v2`。
- 历史拉取的 REST 路径推迟到持久化 intent。
- 排除：透传 pi 原始事件；服务端事件回放（[ADR-0005](0005-client-protocol.md)）；整数会话标识。
