# ADR-0053: 输出回显遮罩：已登记变量的真值换回占位符

状态：实施中  
日期：2026-10-20  
可逆性：高  
取代：无  
被取代：——  
引用入口：[ADR-0007](0007-private-variables.md)；[ADR-0051](0051-placeholder-substitution.md)

## 背景
真值经环境变量进入命令后，命令自己可能把它打印出来（`echo`、`env`、报错里带出连接串），文件里也可能本来就写着它。这些文本一旦进入工具结果，就会进模型上下文、事件帧、会话文件和审核模型的证据。

## 决定

### 做什么
工具结果里出现已登记变量的真值，就精确替换成 `@name`。只做确定性精确匹配：
- 值短于 `MASK_MIN`（8）的不参与，否则 `abc` 之类会把无关文本打烂；
- 同一位置多个值都匹配时取最长的；
- 编码后的回显（base64、URL 编码、被拆开打印）匹配不到。这是已知局限，不做近似匹配。

### 在哪里做
两层，覆盖面互补：

| 层 | 位置 | 覆盖 |
|---|---|---|
| bash 输出 | 包住 bash 的 `operations.exec`，在 `onData` 之前遮罩 | 流式更新帧、SDK 截断后落盘的全文、被中止/超时的错误文本 |
| 工具结果 | 扩展的 `tool_result` 钩子 | `read`、`grep`、MCP、工具抛出的错误；`structuredContent` 与 `details` 递归遮罩 |

`tool_result` 钩子在 `tool_execution_end` 与消息落盘之前运行，所以事件帧、会话文件、审核证据读到的都是遮罩后的文本。图片块不动。

### 流式
值可能被切在两块之间。`StreamMasker` 只滞留“可能是某个值开头”的尾部（最多 `maxLen-1` 个字符），其余立即放行；一个已完整的值若同时是更长值的前缀，也等到能区分再放行。多字节字符被切开同样滞留（`StringDecoder`）。结束或出错时必须 `end()` 冲出尾部。

### 清单来源
每次调用取最新的已登记变量，登记后立即生效，不缓存。清单里没有可遮罩的值时不包装、不改结果。

## 已知局限
- 登记之前已写入会话文件的内容不会回溯遮罩。
- 用户自己在对话里键入的值不处理：那是用户的选择。
- 工具以外的路径（模型自己的回复文本里复述值）不在此层；值本来就不会进入它的上下文。
