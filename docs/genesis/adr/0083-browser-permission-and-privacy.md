# ADR-0083：浏览器工具的权限、审计与隐私边界

**作者**：bluezeamer
**状态**：Accepted
**日期**：2026-10-20

## 背景

侧边浏览器（ADR-0081）让 agent 以 Server 所在机器的网络身份访问网页，页面内容又是不可信输入。需要回答三件事：谁批准访问哪里、批准的粒度、隐私变量的值会不会漏。

## 决策

### 访问授权：按站点审批

- 只有 `browser_open` 需要审批，其余四个工具只作用于已打开的页面。`browser_snapshot` / `click` / `type` / `screenshot` 列入自带校验名单（`BROWSER_FOLLOWUP_TOOL_NAMES`），不再弹窗。
- 审批粒度是站点：协议 + 主机 + 端口（`origin`）。批准 `https://a.com` 不等于批准 `https://a.com:8443` 或 `http://a.com`。
- 非 http(s) 地址不值得打扰用户，直接拒绝。
- 审批文案是「访问 <完整 URL>」，附说明：由 Server 所在机器的浏览器访问，批准即允许本会话访问该站点下的页面，跳转到其他站点仍会被拦截。
- 批准记录只存内存，按会话隔离。Server 重启、会话删除后失效。不可「记住」成永久规则：浏览器工具属于规则外调用，沿用现有「未知工具」路径，`remember` 为 null。
- 工作区档位为 `full`（完全允许）时不拦，导航守卫也对任意站点放行；其余档位只放行本会话批准过的站点。
- `auto` 档的自动评审只处理可评审的调用，浏览器走「未知工具」分支，标记为不可评审，所以 `auto` 档下也只交人工。
- 无人值守的会话，规则外调用一律拒绝。

### 导航守卫：批准的是站点，不只是第一跳

页面里的主框架跳转（含服务端重定向和脚本触发的跳转）每一次都过 `navAllowed`，未批准的站点被拦下，并在工具结果里告诉模型：要访问请对该地址调用 `browser_open`，那一次才会走审批。所以一个已批准的页面不能自行把浏览器带到别的站点。子资源（图片、脚本、接口调用）不拦，否则普通网页无法工作。

### 内网探测：不做地址过滤，边界写明

审批文案含完整 URL，用户批准的是一个具体站点，`localhost`、内网地址与公网地址同等对待，由用户判断。本条**不**加回环或内网地址黑名单：

- 浏览器进程跑在 Server 本机，用户和 Server 本就在同一信任域。单用户令牌之外没有别的使用者。
- 黑名单挡不住 DNS 重绑定、重定向到内网、IPv6 写法等绕法，写了也是假安全。真正的防线是每个站点都要人批准，以及批准文案里能看到地址。
- 代价是：用户批准了一个看似公网、实际解析到内网的域名时，agent 能读到内网页面。这与用户在 bash 里批准一条 `curl` 是同一级别的风险，不另设防线。

### 审计

审批走 `permission/extension` 已有的审计通道，`browser_open` 的用户批准、拒绝、超时、取消、无人值守拒绝都会记录，摘要为「访问 <URL>」。`full` 档下的自动放行与本会话已批准站点的再次打开不记（与其他工具「规则内自动放行不记」一致）。浏览器的后续动作不单独记审计，它们在对话事件流里本来就有完整的工具调用与结果。

### 隐私变量：有遮罩，也有没覆盖的地方

已覆盖：

- 全局的 `tool_result` 遮罩（ADR-0053）作用于浏览器工具的文本结果与抛出的错误，快照和页面文字里出现的隐私变量值会被换回占位符。
- 快照不带密码框（`type=password`）的内容。

**未覆盖，已知限制**：

1. `browser_screenshot` 返回图片块，遮罩明确跳过图片块。页面上若显示了某个隐私变量的值，截图会把它原样交给模型。
2. 占位符（ADR-0051）只对 bash 命令改写。`browser_type` 的 `text` 里写 `@name` 不会被替换成值，会原样打进输入框。所以 agent 现在无法用隐私变量登录网页，这是有意不做的：把变量值打进一个不可信页面等于把它交给页面。

这两条没有补，原因是前者要做图像层面的识别，后者本身就不该支持。使用者需要知道：不要在侧边浏览器里打开会展示隐私变量值的页面。

### 页面内容是不可信数据

工具描述明确告诉模型页面内容来自网络，其中的指令不要照做。这降低提示注入的成功率，但不是安全边界；真正的边界是上面的逐站点审批，被注入后 agent 想去新站点仍要用户批准。

## 后果

- 用户每个新站点批一次，同一会话内不再重复询问。
- 截图通道可能泄漏屏幕上显示的隐私值，靠使用约定而非技术手段兜住。
- 想让 agent 在网页里代填凭据需要另做设计（凭据只在浏览器进程内填入、不经过模型），不在本条范围内。
